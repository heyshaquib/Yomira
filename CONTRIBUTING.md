# Contributing to Yomira

First off, thank you to the open source community for considering contributing to Yomira! It is the passion and collaboration from the community that makes open source truly great.

## Code of Conduct
By participating in this project, you are expected to uphold a welcoming, inclusive, and respectful environment. Please be kind in all discussions, pull requests, and issues.

## How Can I Contribute?

### Reporting Bugs
This section guides you through submitting a bug report. Following these guidelines helps maintainers and the community understand your report, reproduce the behavior, and find related reports.
* Use a clear and descriptive title for the issue to identify the problem.
* Describe the exact steps which reproduce the problem in as many details as possible.
* Provide specific examples to demonstrate the steps.

### Suggesting Enhancements
* Use a clear and descriptive title for the issue to identify the suggestion.
* Provide a step-by-step description of the suggested enhancement in as many details as possible.
* Explain why this enhancement would be useful to most Yomira users.

### Pull Requests
* **Ensure the application builds successfully** with `./gradlew assembleDebug` before submitting.
* Write clear, concise commit messages. 
* Mention any issues your pull request fixes (e.g. `Fixes #123`).
* Respect the existing code style and formatting.
* For major architectural changes or new features, please open an issue to discuss it first before writing any code.

## Development Setup
1. Clone the repository locally.
2. Open the project in Android Studio.
3. Allow Gradle to sync all dependencies.
4. Run the app on your emulator or physical Android device.

Thanks again for your support and contributions to Yomira!
