# Security Policy

## Supported Versions
Security updates are provided for the latest stable release of Yomira. Please ensure you are running the most recent version before reporting a vulnerability.

| Version | Supported          |
| ------- | ------------------ |
| 1.0.x   | :white_check_mark: |
| < 1.0.0 | :x:                |

## Reporting a Vulnerability
If you discover a security vulnerability within Yomira, please do not open a public GitHub issue. 

Instead, report it responsibly by contacting the maintainer directly at **heyshaquib@example.com** (replace with actual contact method if available, or utilize GitHub's private vulnerability reporting feature).

### Expectations
- We will acknowledge receipt of your vulnerability report as soon as possible.
- Please provide detailed steps to reproduce the issue.
- We will work to patch the vulnerability and release an update. We cannot guarantee specific response times, but we treat security issues with high priority.
